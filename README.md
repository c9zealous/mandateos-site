# mandateos-site

Public website for MandateOS: https://c9zealous.github.io/mandateos-site/

This repository contains only the static site files (GitHub Pages, served from the root of `main`). The product repository is private; no product code or internal documents live here.

Sandbox access and pilot calls are requested through this repo's issue templates ("Request sandbox access" / "Book a pilot call"). Issues are public — share only contact details you are comfortable making public.
